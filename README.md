# 职场超人：打工人的逆袭 — 网页试玩

第一人称 3D 职场模拟 Demo。竖屏 375×812，触屏与键鼠均可操作。

- **首页 `index.html`**：真 3D 小人的版本（程序化低模 3D 人物，可转身、迈步、坐下）
- **`v13.html`**：另一条分支的 v1.3（新手任务链 / 试用期任务链 / 四项属性 / 存档 / 音效）

单文件页面，贴图与代码全部内联，无需网络即可运行。

## 操作
- 移动：左下虚拟摇杆（键盘 WASD）
- 交互：右下 `F`（键盘 F）
- 转头：拖屏幕空白区（键鼠拖拽 / 方向键）
- 视角切换：`R`（3D 第一人称 ↔ 2D 俯视）
